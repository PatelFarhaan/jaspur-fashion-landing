# Jaspur

A responsive landing page for Jaspur, a sustainable fashion discovery platform that helps consumers find eco-friendly outdoor and active lifestyle brands.

## Tech Stack

- **HTML5**
- **CSS3**
- **Bootstrap 4.5**
- **jQuery 3.5**

## Features

- Fully responsive design with mobile breakpoints
- Hero banner with overlay text
- Brand spotlight section showcasing sustainable fashion partners
- Category-based brand recommendations (Hiking, Fitness, Surf, Skate, Snow, Running, Biking, Paddling)
- Mission and values presentation
- Call-to-action signup sections
- Social media integration footer

## Prerequisites

- Any modern web browser
- (Optional) A local HTTP server for development

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd jaspur
   ```

2. Open directly in a browser:
   ```bash
   open index.html
   ```

   Or serve with a local HTTP server:
   ```bash
   python3 -m http.server 8080
   ```

## How to Run

Open `index.html` in any web browser, or navigate to `http://localhost:8080` if using a local server.
